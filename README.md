⚡ Electricity Billing System (Java)

📌 Overview
This project is a Java-based system developed to calculate electricity bills based on TNB billing guidelines. It uses an array of objects to manage multiple user records and supports operations such as adding, searching, displaying, and deleting records.

🎯 Objectives : 
1) Implement object-oriented programming concepts in Java
2) Manage multiple user records using an array of objects
3) Simulate real-world electricity bill calculations
4) Practice data handling and basic system operations


⚙️ Features
1) User Record Management - 
Add multiple user records interactively
2) Display All Records - 
View all stored user data with validation for empty entries
3) Search Functionality - 
Search user records by user ID
4) Delete Record - 
Remove user data by setting the object to null
5) Electricity Bill Calculation - 
Calculate total bill based on usage
6) SST & KWTBB Calculation - 
Includes additional charges to compute final payable amount
